# Minilab: constitutional runtime for business operations

**Long-form narrative:** [business-runtime.md](business-runtime.md) (definition, problem, layers, ingress, GTM wedge, proof standard, build sequence).

**Minilab** governs business work as a runtime: work runs only when intent is **admissible**, **policy-permitted**, **realizable**, and **evidentially closed** — not merely because a model said so.

It is not a chatbot swarm, RPA+LLM layer, or prompt soup. It is: human natural language → strong intent → **canonical semantics** (policy, capability, authority, evidence) → **compact runtime** → **evidence closure**.

## Problem

Typical AI ops collapse meaning, permission, and execution into one layer; burn premium tokens on missing structure; rent trust at runtime; scatter operational memory.

## Layers


| Layer               | Role                                         |
| ------------------- | -------------------------------------------- |
| Human language      | Intention, taste, authority                  |
| Strong intent       | Campaigns, plans, exceptions                 |
| Canonical semantics | Meaning, policy, capability, evidence duties |
| Runtime             | Continuous, low-entropy, cheap execution     |


## Company as runtime

Departments are **jurisdictions**: Research, Sales Ops, Marketing, SDR, Compliance, Memory/Analytics. The founder holds **constitutional** amendment authority. Compliance **enforces** but does not silently rewrite its own rules.

## Ingress ladder

L0 deterministic · L1 cheap translator · L2 Place Agent · L3 premium **exception** (logged, budgeted). **Target:** premium usage approaches **zero** in healthy steady state — intelligence harvested into **structure**.

## GTM wedge

First proof is narrow: one ICP, persona, pain, offer, channel, booking path. See [30-day rollout](../operations/gtm-30-day-rollout.md).

## Discipline

Change the core only when production proves missing semantics, wrong admissibility, broken lowering, or insufficient evidence — not for opportunistic features.

## Claim

Minilab is for organizations that want **intelligence compiled into structure**: execution that is not sovereign without closure, and trust that is **structural**, not rented per request.
